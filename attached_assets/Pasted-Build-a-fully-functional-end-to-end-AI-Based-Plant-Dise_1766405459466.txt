========================
BACKEND REQUIREMENTS (app.py)
========================

- Create a Flask app with proper configuration
- Load CNN / Transfer Learning model from "plant_disease_model.h5"
- Load disease labels from class_labels.json
- Load disease details from disease_info.json
- Accept image upload from frontend
- Validate uploaded file type (jpg, jpeg, png only)
- Save uploaded image to static/uploads/
- Preprocess image:
  - Resize to 224x224
  - Convert to RGB
  - Normalize pixel values
  - Expand dimensions for model input
- Perform prediction using model.predict()
- Extract:
  - Disease name
  - Confidence score (percentage)
- Fetch disease details:
  - Symptoms
  - Causes
  - Treatment
  - Prevention tips
- Pass all results to frontend using Flask Jinja
- Handle errors gracefully (no crashes)
- Run Flask server on:
  host = 0.0.0.0
  port = 3000
  debug = True
