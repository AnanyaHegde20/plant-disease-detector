# 🌿 Plant Disease Detection System

An AI-based Plant Disease Detection web application that identifies plant leaf diseases using Machine Learning and provides prediction results through a user-friendly web interface.

---

## 📌 Project Overview

This project helps farmers and agriculture enthusiasts detect plant diseases at an early stage by uploading leaf images. The system uses a trained Machine Learning model (or a mock model during development) to predict diseases and display results instantly.

The application is built using **Python (Flask)** for the backend and **HTML, CSS, JavaScript** for the frontend.

---

## 🚀 Features

- 🌱 Upload plant leaf images
- 🤖 AI/ML-based disease prediction
- 📊 Displays disease name and confidence
- 🌐 Web-based interface
- ⚙️ Mock model fallback if trained model is unavailable
- 🧪 Easy to extend with real trained models
